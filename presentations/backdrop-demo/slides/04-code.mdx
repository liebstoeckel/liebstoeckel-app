## The entire integration

```tsx
import { Present } from "@liebstoeckel/engine";
import { Aurora } from "./elements/Aurora";

<Present
  slides={[Title, How, Cheap, Code, Closing]}
  backdrop={Aurora}
/>
```

A backdrop is a component receiving `still?: boolean`. Render motionless when
it is set, animate with CSS keyframes when it is not, and the engine handles
every surface: live deck, thumbnails, print, capture, presenter.
