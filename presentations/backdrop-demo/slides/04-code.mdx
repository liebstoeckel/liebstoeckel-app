## The entire integration

```tsx
import { Present } from "@liebstoeckel/engine";
import { Aurora } from "./elements/Aurora";

<Present
  slides={[Title, How, Cheap, Code, Steer, Closing]}
  backdrop={Aurora}
/>

// in a slide that wants its own sky
export const backdropProps = { palette: "ember" };
```

A backdrop is a component receiving `still?: boolean`, `slide?: number` and its
own props from the slide. Render motionless when `still` is set, animate with
CSS keyframes when it is not, and the engine handles every surface: live deck,
thumbnails, print, capture, presenter.
